# The Codex matrix: a separate view

A snapshot of the catalog, counted on 10 October 2026.

This catalog contains **287 headings**: **195 families from an older register**, retaining **708 source rows**, plus **92 later additions**. A heading keeps related evidence together. It can cover a reported problem, a recurring pattern, an audit finding, a test result, a limitation or an improvement request.

The older families follow the recurrence links already present in their source. The later additions bring further reports and reviews into the catalog; they can concern older events too. These columns describe how the catalog was assembled. The underlying evidence has not all been independently verified.

A heading can contain several records, and several headings can describe aspects of the same incident. Counts of reports, error messages and test conditions also have different meanings. The number of independent incidents remains unknown. The categories help readers find related evidence; they do not establish a shared cause.

Recorded dates in this catalog span **22 July to 10 October 2026**. They include declared event dates, report dates and audit dates. Some entries have no established date. The earliest located record gives a starting point for investigation; the true first occurrence of each problem remains unknown.

Historical records contain labels such as open, fixed, mitigated and monitoring. Those labels describe the evidence recorded at the time. A reported repair or a passing test does not establish current live behavior. A verified current total of open or fixed problems is therefore not available in this overview.

This separate Codex view sits alongside the existing TT matrix, which already includes Codex-related entries. The views overlap, and their totals must not be added. Any future combined view needs a comparison of the underlying records before its counts can be reconciled.

Future updates should add observed evidence, retain earlier records and explain changes in status or grouping. Reports, demonstrated defects, test findings and unresolved risks should stay distinguishable as the catalog grows.
