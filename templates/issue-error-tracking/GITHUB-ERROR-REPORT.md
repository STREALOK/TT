This is a public observation form, not a request for full logs.

**Observation**
Safe description/signature, operation and relevant version.
Observed time or unknown; recorded time. Expected / unexpected / unknown.
Transient / persistent / unknown.

**Outcome and evidence**
What failed, was blocked or recovered? What does the selected evidence show?
Keep copied private paths, identities, credentials and held source bodies out.

**Count and grouping**
Occurrences or unknown, observation window, attempts and deduplication rule.
State whether this is a new occurrence, a retry or a copied report.
A log update is not automatically an additional error.

**Linked issue and next step**
Link a known issue or leave untriaged. State what would be needed to reproduce
or investigate it. Do not infer a cause merely from the observed message.

**Rettledning på norsk**
Beskriv hendelsen trygt, oppgi relevant versjon og behold ukjente verdier.
Skill observert tidspunkt fra registrert tidspunkt, og feilhendelser fra
oppdateringer i loggen. Fjern private navn, stier, betroelser og beskyttet tekst.
